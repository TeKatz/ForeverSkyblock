# Machine visual source assets

The SVG files here are the editable native sources emitted by `../build_visual_assets.py`; CairoSVG rasterizes them into the packaged 32px motifs and material atlases. They do not require an image service at build or runtime. The script leaves the checked-in generated panel atlas untouched.

`mod/src/main/resources/assets/forever_skyblock/textures/block/machine_panels.png` was created with the built-in Imagegen tool, then imported at 256 × 256 pixels using nearest-neighbor resampling. Its four existing UV quadrants are retained. TeKatz owns the project identity.

## Final Imagegen prompt

Use case: stylized-concept. Asset type: ONE production texture atlas for a Minecraft industrial machine mod, not a mockup. Create a perfectly square 2x2 grid of FOUR equal square panels, edge-to-edge with NO gutters, NO outside border, no text, no numbers. All are crisp authored pixel art, native Minecraft mod style, readable low-frequency material details, dark blue graphite casing and brushed titanium edges with restrained copper and cyan indicators. Straight-on flat orthographic square textures, no perspective. Top-left square: graphite machinery side panel, perimeter metal frame, six horizontal black inset ventilation slats in upper half, small thin cyan illuminated inspection display in lower half, 4 corner bolt heads. Top-right square: machinery top plate, graphite perimeter and four bolts, central square copper hatch with small gray grille, thin cyan inset channels. Bottom-left square: ascension chamber side, restrained pearly titanium and graphite, two vertical violet energy rails inset into dark center, four corner bolts. Bottom-right square: ascension top, concentric square graphite and titanium frames, violet central diamond crystal socket, subtle thin violet circuitry lines. Every square must occupy precisely one quarter with its own clean rectangular border. Unlit industrial pixel art, blocky deliberate pixels, limited colors, attractive hand-crafted texture, no blurry painted noise, no gradients, no shadows outside the panels. Intended to be sampled as exact top-left, top-right, bottom-left, bottom-right UV quadrants.
